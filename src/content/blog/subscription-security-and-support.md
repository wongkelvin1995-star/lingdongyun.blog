# 订阅安全、防泄漏策略与官方客服支持渠道指引：全面守护您的数字凭据

在网络加速服务的使用过程中，**订阅链接（Subscription URL）** 是连接您的个人账户与灵动云分布式节点集群的核心枢纽。由于订阅链接中内嵌了与您账户绑定的专属加密鉴权令牌（Token），它的重要程度堪比您的银行卡临时动态密码。

然而，在日常技术交流中，因粗心截图将完整订阅 URL 暴露在微信群、QQ群、GitHub Issue 或技术论坛导致流量被盗用的案例屡见不鲜。

本文将全面梳理订阅凭据的安全防护准则，并为您介绍灵动云官方技术支持与工单对接的正规渠道。

---

## 一、为什么必须高度重视订阅链接的安全？

```
      [ 您的专属订阅链接: https://.../api/v1/client/subscribe?token=XXXXXXXX ]
                                        │
                         包含高权限身份认证 Token
                                        │
           ┌────────────────────────────┴────────────────────────────┐
           ▼                                                         ▼
   【被恶意他人获取后】                                      【造成的直接后果】
   1. 任何第三方客户端可直接导入节点                     1. 账户流量被他人疯狂消耗殆尽
   2. 并发连接数异常飙升                                  2. 触发系统安全风控限制
   3. 节点连接可能被异地挤占                              3. 影响您自己的正常跨国网络业务
```

### 1. 订阅链接的身份对等性
客户端向服务器同步节点列表时，依靠 URL 后缀携带的 `token=` 字符串进行身份判定。服务器**认 Token 不认人**。这意味着任何掌握该 Token 的人，都具备拉取节点并建立代理连接的同等权限。

### 2. 避免以下高危行为
- **截屏分享时未打码：** 在求助排错时，直接截图整个客户端设置界面，将订阅地址完整暴露；
- **配置跨设备同步时公开发布：** 将包含个人订阅的 Clash 配置文件直接提交到 GitHub 的公开仓库（Public Repo）；
- **借给非信任的熟人：** 对方可能转手分享给他人，导致该订阅在几十台设备上并发连接，导致流量秒级耗尽。

## 二、订阅疑似泄露时的应急处置三步法

如果您在官方后台发现**流量消耗速率异常**，或客户端日志中频繁提示并发设备数超限，请立即按以下步骤处置：

### 第一步：立即登录官方用户中心
通过官方主站[灵动云用户中心](https://varnexa.lingdongaff.com/#/?code=HHoxxHGa)完成账号安全登录。

### 第二步：一键重置订阅信息
在控制台的「我的订阅」或「安全设置」板块中，找到 **「重置订阅链接 (Reset Subscription)」** 按钮并点击确认：
- 执行重置后，旧的 Token 会在 10 秒内彻底失效，任何持有旧链接的人将无法再拉取节点或建立连接；
- 系统会自动生成一串全新的加密 Token 和新订阅链接。

### 第三步：在您的所有合法设备上重新导入
在您自己的手机、电脑、平板客户端中，删除旧订阅配置，重新导入新生成的订阅链接，即可恢复正常使用。

灵动云注重每一位用户的服务体验。为了保证问题排查的真实性与数据安全，请务必认准官方技术支持渠道：

### 1. 在线工单系统（首选与最高优先级）
- **入口：** 登录官方用户中心 -> 点击「技术工单 (Tickets)」->「创建新工单」；
