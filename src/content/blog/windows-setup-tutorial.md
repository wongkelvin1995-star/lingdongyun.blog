# Windows 平台配置与客户端连接完全指南：Clash Verge Rev 与 Mihomo Party

Windows 系统作为日常桌面办公与生产力的核心平台，拥有极其丰富成熟的网络代理客户端生态。目前，基于开源 **Mihomo（Clash Meta）内核** 构建的 **Clash Verge Rev** 与 **Mihomo Party** 是兼具现代视觉体验、低系统资源占用与高稳定性的首选工具。

本教程将详细介绍从获取灵动云订阅到在 Windows 系统上完成全功能配置的完整步骤。

---

## 一、前期准备工作

在开始配置前，请确保您已具备：
1. 运行 Windows 10（64位）或 Windows 11 的电脑设备；
2. 灵动云账号及有效套餐（若尚未订购，请前往[套餐价格页面](/pricing/)选购）；
3. 官方用户中心获取的 **订阅链接**。

---

## 二、首选推荐：Clash Verge Rev 配置步骤

### 1. 下载与安装
访问灵动云[客户端下载中心](/download/)，找到 Windows 平台的 **Clash Verge Rev** 安装包（通常为 `.msi` 或 `.exe` 安装程序），根据提示完成安装并运行。

### 2. 导入灵动云订阅
1. 登录[灵动云官方用户中心](https://varnexa.lingdongaff.com/#/?code=HHoxxHGa)；
2. 进入「仪表盘」或「我的订阅」，找到「一键导入」或点击「复制订阅链接」；
3. 打开 Clash Verge Rev 客户端，点击左侧菜单栏的 **「订阅 (Profiles)」**；
4. 在顶部输入框粘贴您的专属订阅链接，点击 **「保存并导入 (Save / Import)」**；
5. 导入成功后，在订阅列表中右键点击该订阅，选择 **「设为激活 (Use)」**。

### 3. 选择节点与分流规则
1. 点击左侧 **「代理 (Proxies)」** 菜单；
2. 推荐选择 **「规则 (Rule)」** 模式（系统将自动分流境内外流量）；
3. 在节点分组（如「节点选择」或「PROXIES」）中，点击选择您心仪的地区（例如：中国香港、日本或美国）；
4. 点击右下角闪电图标可发起节点连通性延迟测试。

### 4. 开启系统代理或 TUN 模式
- **常规浏览器浏览：** 在客户端首页开启 **「系统代理 (System Proxy)」** 开关即可；
- **全系统深度接管（开发工具、游戏、终端命令行）：**
  1. 打开客户端 **「设置 (Settings)」**；
  2. 找到 **「TUN 模式 (TUN Mode)」** 并点击安装/开启虚拟网卡驱动；
  3. 开启 TUN 模式后，系统所有软件（包括不支持系统代理的命令行终端）将无缝接入加速。

## 三、备选工具：Mihomo Party 快速入门

如果您偏爱极简卡片式风格，**Mihomo Party** 同样是一款出色的现代客户端：
1. 安装后打开界面，在左下角点击齿轮设置；
2. 选择「添加订阅」-> 粘贴灵动云链接并命名；
3. 点击更新订阅，回到主面板点击「启动连接」；
4. 点击节点卡片即可一键切换不同的区域路线。

## 四、Windows 平台常见问题与排错

### 1. 开启代理后无法上网，关掉代理正常？
- **排查步骤 A：** 检查电脑系统时间是否准确。如果 Windows 系统时间与网络标准时间偏差超过 60 秒，将导致 TLS 证书握手失败。请在 Windows 设置中点击「同步时钟」。
- **排查步骤 B：** 检查订阅是否过期或流量是否耗尽。登录官方控制台核对套餐剩余额度。

### 2. 浏览器可以访问，但 VS Code 或终端拉代码报错？
- 浏览器的「系统代理」仅对支持系统全局 HTTP 代理的应用程序生效；
- 建议直接在 Clash Verge Rev 中开启 **TUN 模式**，即可实现网络层透明劫持，无需为 Git 或 NPM 单独配置代理环境变量。
