# iOS 平台常用客户端与规则配置指南：小火箭 Shadowrocket、Loon 与 Stash

苹果 iOS / iPadOS 系统凭借严格的沙盒机制与卓越的系统调度，在代理连接稳定性和能耗表现上极具优势。但由于 App Store 区域政策限制，网络代理工具通常需要通过非国区（如美区、港区）Apple ID 进行下载。

本文将以 iOS 生态中装机普及率最高的 **Shadowrocket（俗称小火箭）** 以及进阶工具 **Loon** 和 **Stash** 为核心，详细介绍如何导入灵动云订阅。

---

## 一、软件获取说明

- **Shadowrocket（小火箭）：** 最广为人知、操作最简捷的经典工具；
- **Loon：** 界面精致、动效流畅，支持强大的策略组与节点连通性图表；
- **Stash：** iOS 上的原生 Clash 内核衍生工具，完美继承 Clash 配置逻辑。

*注：以上软件属于第三方付费应用，需使用海外 Apple ID 登录 App Store 后自行下载。灵动云官方不代售第三方 App，请注意保护账号安全。*

## 二、Shadowrocket（小火箭）快速上手四步法

### 步骤一：复制订阅或扫码
1. 用 Safari 浏览器登录[灵动云用户中心](https://varnexa.lingdongaff.com/#/?code=HHoxxHGa)；
2. 在「我的订阅」板块，选择「一键导入到 Shadowrocket」；
3. 如果未直接唤起，可点击「复制订阅链接」或在电脑端展示「订阅二维码」。

### 步骤二：在客户端添加节点配置
1. 打开 Shadowrocket，点击右上角 **「+」** 加号；
2. **类型（Type）：** 点击并下拉选择 **「Subscribe」**（订阅）；
3. **URL：** 粘贴刚刚复制的灵动云专属订阅链接；
4. **备注（Remark）：** 输入 `灵动云`；
5. 点击右上角 **「保存 (Save)」**，软件会自动向服务器请求并拉取全部优质节点列表；
6. 以后需要更新节点时，只需在订阅名称这一栏向左轻扫，点击「更新」即可。

### 步骤三：选择全局路由与节点
1. 回到主界面，在「全局路由」一栏，务必确认为 **「配置 (Config)」** 模式（请勿选择代理或直连，配置模式才会自动分流）；
2. 在展开的服务器列表中，点击选中您想使用的区域节点（如香港 01、日本 01 等），选中项左侧会出现黄色圆点标记。

### 步骤四：开启连接并授权 VPN
1. 点击最上方的「未连接」开关；
2. 首次开启时，iOS 系统会弹出授权提示框：「“Shadowrocket”想添加 VPN 配置」；
3. 点击 **「允许」**，按屏幕提示验证锁屏密码或 Face ID / Touch ID；
4. 状态栏出现「VPN」图标，即表示灵动云网络加速已成功启用！

## 三、进阶技巧：开启「按需连接」与自动化

很多用户希望手机在离开家里的 Wi-Fi 时自动开启代理，或者在熄屏待机时更省电：
1. 打开小火箭，点击全局路由下方的「通用」设置；
2. 找到 **「按需连接 (On Demand)」** 并开启；
3. 还可以通过 iOS 原生 **「快捷指令 (Shortcuts)」**，设置当打开特定 App（如 YouTube、X 等）时自动开启代理，退出时自动关闭。

## 四、安全提示与使用规范

1. **切勿泄露订阅链接：** 订阅链接包含鉴权密钥，若在公共网络泄露可能会导致他人蹭用您的流量配额；
2. **定期更新订阅：** 灵动云运维团队会定期优化节点路由与服务器 IP，建议每周在客户端左滑刷新一次订阅。
